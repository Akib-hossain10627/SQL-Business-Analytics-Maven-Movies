Project Title:SQL Business Analytics Project | Maven Movies Database

Project Overview:
This project analyzes the Maven Movies database using SQL to answer real-world business questions related to revenue, customer behavior, 
inventory utilization, staff performance, and rental trends. The objective is to demonstrate SQL proficiency while generating actionable business insights that support data-driven decision-making.

7. Key Findings 

Key Findings

• Identified the film category generating the highest total revenue.

• Ranked the top five customers based on lifetime spending and average payment value.

• Measured staff performance by total payments processed and revenue generated.

• Determined the busiest rental month to understand seasonal demand.

• Identified films available in inventory but never rented, highlighting unused stock.

• Compared revenue generated across countries to identify high-performing markets.

• Compared rental frequency between active and inactive customers.

• Identified the actor appearing in the highest number of films.

Key SQL Concepts :
INNER JOIN,LEFT JOIN,GROUP BY,ORDER BY,LIMIT,CASE,WITH CTE,COUNT,SUM,AVG,MIN,MAX,DATEDIFF,DATE_FORMAT

Conclusion:
This project demonstrates my ability to solve business problems using SQL by transforming raw relational data into meaningful insights. 
Through complex joins, aggregations, CTEs, and analytical queries, I gained hands-on experience in business intelligence and data analysis using a real-world database.
